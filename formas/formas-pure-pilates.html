Formas Pure Pilates — padrão para e-mails

As 4 formas reproduzidas em HTML pronto pra colar. Técnica única: tabela + bgcolor + border-radius (cada canto na ordem superior-esq · superior-dir · inferior-dir · inferior-esq).

Compatibilidade: ✅ Gmail (web/app), Apple Mail, Yahoo, iOS, Android renderizam os cantos perfeitamente. ⚠️ Outlook para Windows (desktop) ignora border-radius e mostra a forma como retângulo de cantos retos — a cor e o tamanho ficam certos, só perde o arredondamento. Se um disparo for crítico pra base Outlook-desktop, a gente troca a forma por imagem PNG (idêntica em todo lugar). Para Gmail — que é o seu caso — o HTML abaixo já entrega.
 
✅ Reproduz bem

1 · Banner largo — ponta direita + canto reto (rabinho)

Lado direito em arco forte + canto inferior-esquerdo reto (o "rabinho" da assinatura Pure: 3 cantos redondos + 1 reto).

border-radius: 80px 140px 140px 0 
<table role="presentation" cellpadding="0" cellspacing="0" border="0"
  bgcolor="#C12030" style="background-color:#C12030;
  border-radius:80px 140px 140px 0;width:520px;height:200px;">
  <tr><td>&nbsp;</td></tr>
</table>
 
✅ Reproduz bem

2 · Quadrado — só o canto superior-esquerdo arredondado

Três cantos retos e um arco grande no topo-esquerdo. Boa pra blocos de destaque.

border-radius: 160px 0 0 0 
<table role="presentation" cellpadding="0" cellspacing="0" border="0"
  bgcolor="#C12030" style="background-color:#C12030;
  border-radius:160px 0 0 0;width:260px;height:260px;">
  <tr><td>&nbsp;</td></tr>
</table>
 
✅ Reproduz bem

3 · Folha / pétala (3 cantos redondos + 1 reto)

Mesma lógica dos cards do "Como indicar". O canto inferior-direito vira ponta.

border-radius: 50% 50% 0 50% 
<table role="presentation" cellpadding="0" cellspacing="0" border="0"
  bgcolor="#C12030" style="background-color:#C12030;
  border-radius:50% 50% 0 50%;width:250px;height:250px;">
  <tr><td>&nbsp;</td></tr>
</table>
 
✅ Reproduz bem

4 · "D" — lado esquerdo reto, direito em arco

Esquerda totalmente reta (cantos quadrados), direita em meia-cápsula. Boa pra encostar na borda esquerda.

border-radius: 0 130px 130px 0 
<table role="presentation" cellpadding="0" cellspacing="0" border="0"
  bgcolor="#C12030" style="background-color:#C12030;
  border-radius:0 130px 130px 0;width:250px;height:250px;">
  <tr><td>&nbsp;</td></tr>
</table>
